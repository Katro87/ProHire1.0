Place Poppins and Inter font files here as specified in pubspec.yaml.

Expected files:
- Poppins-Regular.ttf
- Poppins-Medium.ttf
- Poppins-SemiBold.ttf
- Poppins-Bold.ttf
- Inter-Regular.ttf
- Inter-Medium.ttf

You can download these from Google Fonts and add them to this folder. After adding, run:

```
flutter pub get
```

and rebuild the app.
